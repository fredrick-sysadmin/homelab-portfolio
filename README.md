# Home Lab Portfolio

This repository documents my transition into Systems Administration through practical, hands-on learning.

The goal is to recreate real-world IT environments and workflows while documenting build processes, troubleshooting methods, and lessons learned.

## Skills Covered

- Active Directory
- DNS
- DHCP
- Windows Server
- Group Policy
- Azure
- Microsoft 365
- Networking
- Troubleshooting

## Methodology

Build → Break → Troubleshoot → Document → Improve
